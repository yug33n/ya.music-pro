## 2. Контекст и границы задачи (Scope)

### В рамках задачи (In Scope):
- Реализация асинхронного клиента Яндекс Музыки (`YandexApiClient`) на базе `reqwest` с поддержкой `rustls-tls`.
- Авторизация через OAuth Device Code Flow (`ya.ru/device`):
  - Запрос кода устройства (`device_code`, `user_code`, `verification_url`, `interval`);
  - Фоновый поллинг токена с обработкой состояния ожидания (`authorization_pending`);
  - Автоматическое сохранение полученного `access_token` в таблицу `config` локальной базы SQLite;
  - Загрузка сохраненного токена при старте и проверка статуса аккаунта (`/account/status`).
- Генератор прямых ссылок на аудиопоток (MP3 320 kbps и FLAC):
  - Запрос `/tracks/{track_id}/download-info`;
  - Парсинг XML-ответа (`quick-xml`) с извлечением `host`, `path`, `ts`, `s`;
  - Алгоритм криптографической подписи MD5 с солью Яндекс Музыки для формирования валидного прямого URL.
- Эндпоинты каталога, библиотеки и рекомендаций:
  - Получение профиля и подписок пользователя;
  - Получение коллекции «Мне нравится» (лайкнутые треки);
  - Получение пользовательских плейлистов;
  - Полнотекстовый поиск (треки, альбомы, артисты);
  - Эндпоинты «Моей волны» (`/rotor/station/.../tracks`) с передачей параметров настроения и языка;
  - Лайк / дизлайк треков.
- Unit-тесты для парсера XML, MD5-подписи URL и структуры запросов.

### Вне рамок задачи (Out of Scope):
- Потоковое воспроизведение в аудио-карту (запланировано в Issue #03).
- Slint UI экраны отображения треков и колеса вайбов (запланировано в Issue #04).
