## 2. Контекст и границы задачи (Scope)

### В рамках задачи (In Scope):
- Парсер синхронизированных текстов формата LRC:
  - Поддержка форматов `[mm:ss.xx]` и `[mm:ss.xxx]`;
  - Валидация, сортировка строк по таймкодам;
  - Определение активной строки по текущему времени трека (`active_line_index`).
- Двухисточниковый фетчер текстов (Dual-source Lyrics Fetcher):
  - Основной источник: эндпоинт Яндекс Музыки `/tracks/{track_id}/supplement`;
  - Запасной источник (Fallback): открытый API LRCLIB (`https://lrclib.net/api/get`);
  - Автоматическое переключение на fallback при отсутствии синхронизированного текста в Яндексе.
- Полноэкранный режим плеера (`FullscreenView` в Slint):
  - Разворачивание по нажатию клавиши `F`, кнопке в плеере или клику на обложку трека;
  - Размытый градиентный фон под цветовую гамму текущего трека;
  - Левая колонка: крупный постер обложки, название трека, артисты, быстрые кнопки воспроизведения;
  - Правая колонка: вертикальный караоке-скроллер с подсветкой текущей активной строки (акцентный цвет, увеличенный шрифт) и приглушением неактивных;
  - Интерактивная перемотка трека по клику на любую строку текста песни;
  - Кнопка выхода из полноэкранного режима (ESC / кнопка закрытия).
- Unit-тесты для парсера LRC и поиска активных строк.

### Вне рамок задачи (Out of Scope):
- WASAPI Exclusive и Gapless воспроизведение (запланировано в Issue #06).
- 10-полосный эквалайзер и реверберация (запланировано в Issue #07).
